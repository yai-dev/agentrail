# Summarize Text

Given a block of text, produce a clear and concise summary in 2–4 sentences.

## Instructions

1. Read the provided text carefully.
2. Identify the key points and main ideas.
3. Write a summary that captures the essential meaning without unnecessary detail.
4. Return only the summary — do not include any preamble or follow-up questions.
