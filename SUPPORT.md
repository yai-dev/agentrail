# Support

## Documentation

Full documentation is at [agentrail.run](https://agentrail.run).

## Questions and Discussion

For questions, ideas, or general discussion, use [GitHub Discussions](https://github.com/yai-dev/agentrail/discussions).

Please search existing discussions before opening a new one.

## Bugs

For confirmed bugs, open an issue using the [bug report template](https://github.com/yai-dev/agentrail/issues/new?template=bug_report.md).

Please include a minimal reproduction, your environment details (Node.js version, package version, OS), and the full error output.

## Feature Requests

For new feature ideas, open a [feature request](https://github.com/yai-dev/agentrail/issues/new?template=feature_request.md) or start a discussion under the [Ideas](https://github.com/yai-dev/agentrail/discussions/categories/ideas) category.

## Security

For security vulnerabilities, see [SECURITY.md](SECURITY.md). Do not open a public issue.
